# Blog photo credits

One row for every photograph used as a blog cover (`BlogPost.cover`). Add the row **before** the file
goes into `apps/web/public/blog/covers/`. See `blog-covers.md` for the rules.

All photos below are from Unsplash, "Free to use under the Unsplash License" (shown on each photo's
own page on the date checked). Each was viewed before use: no identifiable people, no brands, logos or
readable text, and nothing tied to a real builder's project.
